# GoldPotato TDS

Browser-based multiplayer top-down shooter with pixel/Atari-style graphics.

## Features

- **WASD** controls (W up, S down, A left, D right)
- Mouse aim + click to fire automatic rifle
- Multiplayer rooms (max 10 players per room, host starts the round)
- American office–style map with desks/cubicles as cover
- 3 hearts per player; hearts spawn on the map every 60 seconds
- 10-minute rounds; round ends when only one (or zero) players remain
- Leaderboard top-right; HP bar at lower-center
- After a round, the lobby auto-starts a new round
- Random username on first launch (editable from the menu)
- Wardrobe button shows the same robot character in many color variants

## Run

```bash
npm install
npm start
```

Then open `http://localhost:3000` in your browser. Open multiple tabs to test multiplayer locally.
